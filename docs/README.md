# Tekisuto App Documentation

Welcome to the Tekisuto app documentation! This guide will help you set up and use all the features of Tekisuto, your Japanese text reading assistant with OCR and dictionary integration.

## Quick Start Guide

1. **Enable Accessibility Service** - Required for screen capture functionality
2. **Import a Dictionary** - Add JMdict or other Japanese dictionaries
3. **Configure OCR Settings** - Set up text recognition preferences
4. **Test Screenshot Feature** - Try double-tapping to capture text
5. **Set up AnkiDroid** (Optional) - Export new vocabulary automatically

## Need Help?

If you encounter any issues or have questions not covered in these guides, please check the [GitHub Issues](https://github.com/abaga129/tekisuto/issues) page or create a new issue.

## App Overview

Tekisuto is designed to help Japanese learners by:
- Capturing text from any app or screen
- Providing instant dictionary lookups
- Recognizing text from camera
- Integrating with AnkiDroid for vocabulary building
